# Candidate-aware Offline RL for Rope Manipulation

**Task 2 · Linear Deformable Object Shape Control · Team K-DAS**

This module uses the teacher dataset generated by 2-step MPC to approximate computationally expensive MPC action selection with a fast neural policy. Behavior Cloning (BC) directly imitates the action selected by the teacher, while candidate-aware offline RL goes one step further by learning the **relative quality of both the selected action and the unselected shortlist candidates evaluated from the same state**.

> **Core question**  
> “Can the policy learn not only the single action selected by MPC, but also which alternatives are better and which ones should be avoided?”

---

## 1. Why a Learned Policy?

2-step MPC generated high-quality actions by accounting for future cost, but each step required rolling out many candidates through DER + Residual GNN. On the real robot, actions need to be selected quickly after observation, so repeatedly running MPC remained computationally expensive.

We therefore separated the roles of MPC and the neural network.

- **MPC**: slow, but generates relatively reliable actions and candidate rankings
- **BC/RL policy**: takes the current and target rope states and outputs an action immediately
- **Runtime safety**: adjusts the policy action to real-robot geometry and servo constraints

## 3. Action Representation

The policy predicts a rope-manipulation action as three discrete components.

$$
a_t=(i_{node},\ell_{bin},\theta_{bin})
$$

- **Node index**: which of the 20 ordered rope nodes should be grasped
- **Length bin**: how far the rope should be dragged
- **Theta bin**: in which direction the drag should be executed

The new teacher dataset uses the following length bins to reduce repeated selection of excessively short strokes on the real robot.

```python
DEFAULT_LENGTH_BINS = (
    0.10, 0.15, 0.20, 0.25, 0.30,
    0.35, 0.40, 0.50, 0.60, 0.70, 0.80,
)
```

A continuous teacher length is converted to the nearest discrete-bin index and used as the classification target.

## 5. Behavior Cloning as the Supervised Baseline

BC treats the teacher-selected action as the target and imitates node, length, and theta.

$$
L_{BC}=L_{node}+L_{length}+L_{theta}
$$

Using failed episodes and clearly poor steps as equally valid targets can cause the actor to learn unstable behavior. Therefore, BC uses a **high-quality step dataset**.

The filtering rules were designed according to the following principles.

- Include fine-correction steps near the target, but exclude actions that cause excessive degradation afterward
- Allow correction steps that temporarily worsen error by up to approximately 1 mm
- Use only actions consistent with the new length-bin range
- Do not enforce aggressive node balancing during early training so that frequently required endpoint/keypoint selections are not removed artificially

BC provides a stable initial policy and a strong supervised baseline, but can become unstable when closed-loop execution accumulates states outside the teacher-data distribution.

---

## 6. Why Candidate-aware RL?

Inside MPC, there is not only a single final selected action. Multiple shortlist candidates are evaluated from the same state, and the unselected actions also contain information about **which alternatives were relatively worse**.

BC learns only:

```text
state → selected action
```

Candidate-aware RL additionally uses:

```text
state
selected action
unselected candidate actions
candidate predicted errors / costs
candidate ranking
next state
episode boundary / terminal success
```

The policy is therefore designed to learn not only “what action was taken,” but also “why other candidates were less desirable from the same state” through critic supervision.

---

## 7. Relative Candidate Q Target

Let the predicted mean error of candidate $k$ be $m_k$, and let the best error in the shortlist be $m^*$. The relative Q target is defined as:

$$
q_k^{target}=-\mathrm{clip}\left(m_k-m^*,\,0,\,M\right)\,c_q
$$

- Best candidate: $m_k\approx m^*$, so its Q target is close to 0
- Worse candidate: a larger error gap from the best candidate produces a more negative Q target
- $M$: clipping range that prevents extreme gaps from exploding the target scale
- $c_q$: Q-target scale

Rather than learning the absolute score directly, this formulation uses the **relative quality of candidates within the same state** for critic supervision.

---

## 8. Actor–Critic Objectives

The critic jointly uses Bellman TD learning, candidate-level supervision, and ranking information.

$$
L_{critic}=L_{TD}+\lambda_{qsup}L_{Qsup}+\lambda_{rank}L_{rank}
$$

The actor combines teacher imitation with preference for actions that receive high values from the critic.

$$
L_{actor}=\lambda_{BC}L_{BC}+\lambda_{RL}L_{policy}+\lambda_{cand}L_{candidate}
$$

The role of each term is summarized below.

| Loss | Function |
|---|---|
| $L_{BC}$ | Stable imitation of the MPC teacher action |
| $L_{policy}$ | Prefer actions assigned higher value by the critic |
| $L_{candidate}$ | Incorporate candidate distribution and relative quality |
| $L_{TD}$ | Learn temporal consistency across episode transitions |
| $L_{Qsup}$ | Supervise relative Q targets derived from MPC candidate errors |
| $L_{rank}$ | Preserve candidate ordering |

## 9. The Initial Instability Problem

During early candidate-aware RL training, validation TD loss and qsup loss increased sharply and the critic diverged. The problem was not that the entire candidate distribution was poor, but that **a very small fraction of extreme errors dominated the Q-target scale**.

The key statistics and the effect of clipping are summarized below.

| Metric | Original data / logic | After clipping / qsafe |
|---|---:|---:|
| Candidate error mean | 19.2055 mm | Unchanged |
| Candidate error median | 14.4993 mm | Unchanged |
| Candidate error p95 | 43.5314 mm | Unchanged |
| Candidate error p99 | 51.6757 mm | Unchanged |
| Maximum candidate error | 12,404.6729 mm | Unchanged |
| Error > 100 mm ratio | 0.0223% | Unchanged |
| Error > 500 mm ratio | 0.0111% | Unchanged |
| Error > 1,000 mm ratio | 0.0097% | Unchanged |
| Minimum Q target | −1237.9601 | Hard lower bound: −2 |
| Q target p1 | −0.7281 | qsafe: −0.1456 |
| Q target median | −0.0456 | qsafe: −0.0091 |
| Maximum Q target | 0.0000 | 0.0000 |
| Q target < −2 ratio | 0.0752% | 0% |
| qsup divergence observed | Yes | No |

Most candidates remained within a normal range, but even outliers representing less than 0.01% of the data could generate extremely large gradients under squared or supervised critic losses.

## 10. qsafe Stabilization

`qsafe` is not a separate heuristic policy that changes the relative frequency of node selection. It is a **stabilization configuration that constrains candidate-aware RL Q targets and critic training to a numerically safe range**.

The main stabilization changes were:

| Stabilization item | Setting / role |
|---|---|
| Candidate Q target mode | Relative |
| Candidate metric gap clip | 30.0 |
| Candidate Q scale | 0.02 |
| Q target lower bound | −2.0 |
| qsup coefficient | Reduced |
| Ranking loss | Retained |
| Actor candidate soft loss | Retained |

<p align="center">
  <img src="../../../images/t2_rl04.png" alt="Before and after qsafe training stability" width="760"/>
</p>

The main training-log changes before and after stabilization are summarized below.

| Item | Before stabilization | After qsafe | Summary |
|---|---|---|---|
| Validation TD loss | Rose as high as 26.1249; 23.4958 at E059 | 0.2789 at E100 | 26.1249 → 0.2789 |
| qsup loss | Batch spike of 7838.5371 | Validation 1.7719 at E100 | 7838.5371 → 1.7719 |
| Minimum Q target | Outliers around −2000 | Clipped with lower bound −2 | ≈ −2000 → −2 |
| Validation critic loss | Peak 26.5821 around E053 | 0.3218 at E100 | 26.5821 → 0.3218 |
| Best-checkpoint update | No stable best save during the unstable interval | Best updated at E098; training completed through E100 | best_epoch = 98 |
| Triple accuracy | Approximately 0.155–0.169 in unstable validation | Best validation triple accuracy 0.231 | Improved |
| Ranking loss | 0.6885 at E059; peak 0.7204 | 0.6823 at E100 | 0.6885 → 0.6823 |
| Candidate gap | 0.0810 at E059 | 0.0587 at E100 | 0.0810 → 0.0587 |

Clipping was not merely a performance-tuning trick; it was necessary numerical stabilization to prevent a small number of outliers from destabilizing the entire critic.

These results show that the policy had acquired the ability to approach the target shape, but could still move away again after reaching a near-goal state. Therefore, qsafe should not be presented as a complete solution to every closed-loop failure mode.

## 12. Retraining with the Target-edge w500 Teacher

The teacher dataset was later regenerated using the target-edge w500 GNN and 2-step MPC. BC was retrained on high-quality steps, while RL was retrained using full episode and candidate records.

| Model | Best mean error | Final edge relative error |
|---|---:|---:|
| BC old | Approximately 5.6 mm | Approximately 0.130 |
| BC w500 HQ | Approximately 3.5 mm | Approximately 0.066 |
| RL old | Approximately 5.4 mm | Approximately 0.138 |
| RL w500 | Approximately 3.4 mm | Approximately 0.070 |

The improvement of the new policy should not be attributed to the RL objective alone. It reflects the combined effect of the following pipeline improvements.

1. Improved transition consistency using the target-edge GNN
2. Future-aware teacher generation using 2-step MPC
3. Separate datasets tailored to BC and RL objectives
4. Stabilized candidate Q supervision using qsafe

## 14. BC and RL Are Complementary

| Category | Behavior Cloning | Candidate-aware RL |
|---|---|---|
| Main data | High-quality teacher steps | Full episode + candidate ranking |
| Main objective | Teacher action imitation | High-value action preference + candidate quality |
| Strength | Stable and efficient supervised policy | Accounts for closed-loop distribution shift and candidate comparison |
| Main risk | Error accumulation in states outside the dataset | Critic/Q-target instability |
| Role in K-DAS | Strong baseline / supervised anchor | Additional robustness during difficult rollouts |

The new BC policy itself was already strong. On some seeds, BC w500 HQ could converge faster or reach a lower error than RL. It is therefore more accurate to describe **BC as stable teacher imitation, and RL as a complementary mechanism for learning relative candidate quality and handling closed-loop distribution shift**, rather than claiming that RL is always superior to BC.

## 15. Inference Flow

```python
def select_action(current_rope, target_rope):
    state_feature = policy.encode(current_rope, target_rope)

    node_logits = policy.node_head(state_feature)
    length_logits = policy.length_head(state_feature)
    theta_logits = policy.theta_head(state_feature)

    action = decode_discrete_action(
        node_logits=node_logits,
        length_logits=length_logits,
        theta_logits=theta_logits,
    )

    # The learned output is not executed blindly.
    return runtime_safety_adjust(action, current_rope, target_rope)
```

The policy produces an action faster than MPC, but directed tangent, rotation sign, endpoint limits, geometry risk, and score hold are still applied before real-robot execution.

---

## 16. Limitations

- The initial qsafe rollout success rate was 5/10, so the policy alone did not achieve complete stability
- 8/10 seeds reached a near-goal state, but some later moved away again
- Repeated node selection and near-node repetition were not fully eliminated by qsafe
- Discrete action bins prevent direct representation of a continuous optimum
- Generalization may be limited for rope/material conditions outside the teacher dataset and residual-dynamics domain
- Performance depends strongly on offline-dataset quality and candidate-ranking calibration
- Final real-robot performance depends not only on the policy, but also on runtime safety and release/hold execution

## 18. Takeaway

> **Candidate-aware RL converts MPC’s internal candidate comparison into a fast policy that learns both the selected action and the relative quality of alternatives.**

The K-DAS RL policy is not simply a classifier that reproduces MPC actions. It uses selected and unselected candidates evaluated by 2-step MPC, their rankings, and episode transitions jointly within actor–critic learning. Early training was destabilized by extreme candidate errors, but qsafe stabilized training through relative Q scaling, clipping, and a lower bound. Retraining with the target-edge w500 teacher further improved best mean error and rope-edge consistency, resulting in a fast action policy that could be integrated with the runtime-safety layer.
